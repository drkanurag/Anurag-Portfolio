## 🎯 Architecture & Redesign Overview

This portfolio is engineered as an interactive **AI Systems & Software Engineering Showcase** combining **Direction A (Premium Dark Engineering)** with **Direction C (Interactive AI Systems Lab)** and a one-click **Direction B (Minimal Editorial Light Mode)** switcher.

### Key Engineering Highlights
1. **Interactive Technical Demonstrations ([`src/components/InteractiveProjectLab.tsx`](./src/components/InteractiveProjectLab.tsx))**:
   - **RoadVision AI Inspector**: Interactive before/after pavement distress split-slider, WBF Ensemble bounding-box toggle (`rdd2022_india_trained` + `rdd2022_yolov8n`), Morphological Black-Hat fissure mask, and live **ASTM D6433 Corrected Deduct Value (CDV) → Pavement Condition Index (PCI 0–100)** telemetry.
   - **DataLens Global Manager RLS/CLS Simulator**: Switch between `GDF` (Global Data Foundation) and regional `HRBP-*` personas (`HRBP-BLR`, `HRBP-KOL`, `HRBP-MUM`) to verify Row-Level and Column-Level Security enforcement across the 6-service mesh.
   - **Rooted PostgreSQL 18 3NF Schema & KPI Explorer**: Inspect normalized 3NF DDL constraints, analytical SQL queries, and simulate NGO surplus pickups toward the `75.0%` Food Diversion Rate target.
   - **BLUME Research Benchmark Comparator**: Interactive evaluation of `SSD MobileNet v2`, `YOLO`, `Custom CNN`, and `Haar Cascade` across `mAP@0.5`, `Precision`, `mAP@0.5:0.95`, and `FPS`.
   - **AETHER Weather Client DSA Sandbox**: Test $O(1)$ Doubly-Linked LRU Cache hits, Stull Wet-Bulb ($T_w$) & Magnus-Tetens Dew Point physics, and HTTP 400 ERA5 boundary guards.
2. **8-Section Dedicated Case-Study Pages ([`src/components/ProjectCaseStudyPage.tsx`](./src/components/ProjectCaseStudyPage.tsx))**:
   - Every project includes structured sections for **Problem**, **Solution**, **System Architecture**, **Technology Decisions**, **Engineering Challenges**, **Measured Results**, **Limitations & Next Steps**, and **Verified Links**.
3. **Efficient Client-Side Data Structures ([`src/lib/catalogueEngine.ts`](./src/lib/catalogueEngine.ts))**:
   - `PROJECT_BY_SLUG`: `ReadonlyMap<ProjectSlug, Project>` for $O(1)$ average-time route resolution and skill-to-project cross-referencing.
   - `SKILLS_BY_DOMAIN`: `ReadonlyMap<SkillDomainId, SkillCategory>` grouping competencies by engineering domain rather than arbitrary percentage bars.
   - `NORMALIZED_SEARCH_INDEX`: Pre-indexed lowercase token map for instant search across all 10 repositories.
   - `Set<string>` membership checks for fast domain and technology tag filtering.
